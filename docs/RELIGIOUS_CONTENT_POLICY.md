# Religious content policy

1. **Quran text is never generated, edited or "corrected".** It comes only from the verified Tanzil file. Search normalisation, which strips diacritics, is used only for matching and never for display.
2. **Quranic duas reference ayahs.** Their text is pulled from the dataset at runtime, never typed by hand.
3. **Every hadith-based dua carries a reference** (collection and number). No reference is invented. If a source can't be confirmed, the item is left out.
4. **Hadith come from a published dataset** and show the grades recorded by named scholars. The app does not issue its own gradings.
5. **No AI-generated religious content.** The Ask feature returns verified ayahs. If no AI model is available it says so and never fills the gap with generated text. Any future AI output must be labelled as AI reflection, kept separate from Quran and hadith, and must cite retrieved sources.
6. **Differences of opinion are stated, not ruled on.** Lessons note where schools differ (e.g. what breaks wudu, nisab basis, Hajj types).
7. **Estimates are labelled as estimates.** This covers Zakat, Hijri dates and prayer times, with the user's adjustments respected.
8. **Corrections:** please open a GitHub issue with the item, the problem and a reliable source. Content issues take priority over everything else.
